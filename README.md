# Проектирование высоконагруженных систем: OpenAI API Platform

## 1. Тема и целевая аудитория

### Описание

Проектируемая система — платформа предоставления доступа к большим языковым моделям (LLM) через API. Ключевая особенность — **streaming-генерация ответов**, когда токены отдаются клиенту по мере их генерации моделью в реальном времени.

Реальные аналоги: OpenAI API, Anthropic Claude API, Google Gemini API.

### Целевая аудитория

**Местоположение:** Глобально, основные рынки — США (35%), Европа (25%), Азия (25%), остальные регионы (15%).

**Размер аудитории:**
- MAU: ~250 млн [^1]
- DAU: ~50 млн (оценочно 20% от MAU)
- Пиковые concurrent users: ~10 млн

При этом API-пользователи (разработчики, компании) генерируют значительную часть запросов через автоматизированные системы.

### Распределение по тирам

| Тир | Доля пользователей | RPM лимит | Характер использования |
|-----|-------------------|-----------|------------------------|
| Free | 60% | 3 | Пробное использование |
| Plus ($20/мес) | 30% | 60 | Активные пользователи |
| API/Enterprise | 10% | 1000+ | B2B, автоматизация |

### Требования к функционалу

#### Ключевые функции

| Функция | Описание |
|---------|----------|
| Chat Completions API | Основной эндпоинт для диалога с моделью |
| **Streaming ответов (SSE)** | Отдача токенов по мере генерации |
| Управление API-ключами | Создание, ротация, отзыв ключей |
| История диалогов | Сохранение и доступ к предыдущим чатам |
| Rate Limiting | Ограничение запросов по тирам |
| Подсчёт токенов | Учёт использования для биллинга |

#### Ключевые продуктовые решения

- **Streaming по умолчанию** — ответы отдаются через Server-Sent Events (SSE) по мере генерации токенов, что снижает perceived latency для пользователя.
- **Приоритизация по тирам** — платные пользователи получают приоритет в очереди к GPU-кластерам.
- **Региональное распределение** — API Gateway в 3 регионах, inference-кластеры централизованы для оптимизации использования GPU.
- **Token-based биллинг** — оплата за фактическое использование (prompt + completion токены).
- **Graceful degradation** — при перегрузке бесплатные пользователи получают 429, платные продолжают работу.
