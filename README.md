# 1. Тема и целевая аудитория

## Описание

Проектируемая система — публичная AI API‑платформа, предоставляющая доступ к большим языковым моделям (LLM).

**Основная проектируемая функциональность — потоковая передача ответа модели (Streaming) через Server‑Sent Events (SSE).**

Архитектура системы проектируется с фокусом на обработку долгоживущих HTTP‑соединений и передачу данных частями по мере генерации токенов.

Реальные аналоги:  
OpenAI API, Anthropic API, Google Gemini API, Azure OpenAI Service.

---

## Выделяемая ключевая фича

Streaming-режим:

- Ответ модели передаётся частями (token‑by‑token)  
- Соединение удерживается до завершения генерации  
- Используется протокол `text/event-stream`  
- Основная нагрузка генерируется именно на уровне потоковой передачи данных  

Streaming является ключевой нагрузкообразующей функцией системы и определяет архитектурные решения.

## Целевая аудитория

**Местоположение:** Российская Федерация (все регионы).

### Размер аудитории (оценка)

Исходя из данных о глобальной активности ChatGPT [1] и населения России (~146 млн), принимаем:

| Показатель | Значение |
|------------|-----------|
| MAU | 18 млн пользователей |
| DAU | 2 млн пользователей |
| Активные API-клиенты | ~50–100 тыс. приложений и сервисов |

Основная нагрузка генерируется приложениями, интегрирующими API (чат-боты, AI-ассистенты, SaaS-продукты).

---

## Требования к функционалу

### Ключевые функции

- Создание запроса на генерацию текста (Chat Completion API)  
- Потоковая передача результата по мере генерации (SSE) — **основная фича**  
- Аутентификация по API-ключу  
- Ограничение частоты запросов (Rate Limiting)  
- Подсчёт и биллинг использованных токенов

---

## Ключевые продуктовые решения

- API является stateless — история диалога передаётся клиентом в каждом запросе.  
- Streaming реализуется через SSE поверх HTTP/1.1 или HTTP/2.  
- Inference-кластер (GPU) отделён от API-слоя.  
- Горизонтальное масштабирование API-нод.  
- Глобальная балансировка нагрузки внутри РФ.  
- Сервис работает круглосуточно (24/7).
